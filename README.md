# 2. Musical Chairs

**Rapid Games Prototyping - Week 2**
### [Play Demo on Itch.io](https://jesuspinarte.itch.io/musical-childs)

## Overview
A high-energy local multiplayer (or AI-driven) simulation of the classic party game. The focus was on **State Machine** logic and synchronized events triggered by music cues.

## Technical Implementation
- **State Machine Architecture:** Implemented a robust `GameManager` to handle transitions between _MusicPlaying_, _Scramble_, and _Elimination_ states.
- **AI Pathfinding:** Used NavMesh for NPCs to find the nearest "valid" chair with randomised reaction times.
- **Audio-Sync Logic:** Scripted events that trigger based on audio volume thresholds or track pauses.
    
## Controls
- **Mouse Click:** Select/Claim chair.
- **R:** Restart Round.
